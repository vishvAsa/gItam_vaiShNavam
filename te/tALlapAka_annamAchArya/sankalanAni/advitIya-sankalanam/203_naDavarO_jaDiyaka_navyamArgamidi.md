**Naḍavaro Jaḍiyaka Navyamārgamidi**  
नडवरॊ जडियक नव्यमार्गमिदि  
मडुगदि वैष्णव मार्गमिदि \!॥नड॥  
घन शुकमुख्युलु गन्न मार्गमिदि  
जनकादुल निश्चल मार्गमिदि  
सनत्कुमारुडु जरपु मार्गमिदि  
मनुवुल वैष्णव मार्गमिदि \!॥नड॥  
नलुगड वसिष्ठु नडुचु मार्गमिदि  
यिल वेद व्यासुल मार्गम्बिदि  
बलिमिगलुगु धृवपट्टपु मार्गमु  
मलसिन वैष्णव मार्गमिदि \!॥नड॥  
परम मार्गम्बिदॆ प्रपञ्च मार्गमु  
गुरु मार्गम्बिदॆ गोप्यमिदे  
गरिमॆल श्री वेङ्कटपति माकुनु  
मरिपॆनु वैष्णव मार्गमिदि \!॥नड॥  
**naḍavaro jaḍiyaka navyamārgamidi**  
**maḍugadi vaiṣṇava mārgamidi \!..naḍa..**  
**ghana śukamukhyulu ganna mārgamidi**  
**janakādula niścala mārgamidi**  
**sanatkumāruḍu jarapu mārgamidi**  
**manuvula vaiṣṇava mārgamidi \!..naḍa..**  
**nalugaḍa vasiṣṭhu naḍucu mārgamidi**  
**yila vēda vyāsula mārgambidi**  
**balimigalugu dhṛvapaṭṭapu mārgamu**  
**malasina vaiṣṇava mārgamidi \!..naḍa..**  
**parama mārgambide prapañca mārgamu**  
**guru mārgambide gōpyamidē**  
**garimela śrī vēṅkaṭapati mākunu**  
**maripenu vaiṣṇava mārgamidi \!..naḍa..**  
Tread upon this fearlessly, a new path this is\!  
The path which is pure, the Vaishnava marga\!  
This is the path perceived by great ones like Shuka and others  
This is the constant path of Janaka and others  
This is the path followed by Sanat-Kumara  
This is the Vaishnava marga of the fourteen Manus\!  
This is the path that Vasista followed  
This is the path of Veda Vyasa and others  
This is the path firmly adopted by Dhruva  
This is the superior Vaishnava marga\!  
This is the supreme path, the path of the world  
This is the path of Guru1, the secretive one\!  
The great Sree Venkatapathi Himself  
bestowed upon us, this Vaishnava marga\!  
1\. Sree Ramanujacharya
